# IlmQuest

**IlmQuest** est une application web moderne et interactive conçue pour faciliter l'apprentissage, la mémorisation et la révision des 99 Noms d'Allah. 

L'application a été pensée avec une approche "Mobile-First", offrant une expérience fluide et intuitive, que ce soit sur smartphone, tablette ou ordinateur de bureau.

## 🎯 But de l'application

L'objectif principal d'IlmQuest est d'accompagner l'utilisateur dans son cheminement spirituel et éducatif en rendant l'apprentissage des Noms Divins interactif, mesurable et engageant. 

Au lieu d'une simple liste statique, l'application propose plusieurs outils pédagogiques adaptés à différents styles d'apprentissage :

1. **La Liste Interactive** : Pour parcourir, rechercher et lire les noms en arabe, avec leur translittération et leur traduction.
2. **Les Flashcards (Cartes de mémorisation)** : Pour s'entraîner activement à mémoriser chaque nom. L'utilisateur peut marquer un nom comme "Acquis" pour suivre sa progression.
3. **Le QCM Classique** : Pour s'entraîner sans pression à reconnaître la signification de chaque nom.
4. **Le Mode Défi** : Pour tester ses connaissances de manière plus ludique et tenter de battre son meilleur score.

## ✨ Fonctionnalités clés

- **Suivi de progression** : Un tableau de bord visuel indique le pourcentage de noms maîtrisés.
- **Bilingue (Français / Anglais)** : L'interface et les traductions des noms sont disponibles dans les deux langues.
- **Thème Sombre / Clair** : Pour un confort de lecture optimal de jour comme de nuit.
- **Taille de texte ajustable** : Pour une meilleure accessibilité visuelle.
- **Paramétrage des Quiz** : Possibilité de choisir le nombre de questions (10, 20, 30, 50 ou 99) et d'arrêter un quiz en cours de route.

## 🛠️ Technologies utilisées

- **React 18** : Bibliothèque UI principale.
- **Tailwind CSS** : Pour un design moderne, réactif et entièrement personnalisé.
- **Framer Motion** : Pour des animations fluides (transitions de pages, retournement des cartes, barres de progression).
- **Lucide React** : Pour une iconographie claire et cohérente.
- **Context API** : Pour la gestion de l'état global (Progression, Langue, Préférences utilisateur).
- **LocalStorage** : Pour sauvegarder la progression, le thème et les préférences directement sur l'appareil de l'utilisateur.
